# 190 Expanded x1.5: new regions

99 land regions that are not in base 190E (190E has 240, vanilla 201; now 339). Grouped by province, capital first.
Resource = the region's primary building template in the 3k_main_campaign_map start pos (`start_pos_region_slot_templates`); capital = `is_capital` in `region_to_province_junctions`. Names are the on-screen names from the pack loc. Provinces marked *(existing)* are 190E / vanilla provinces that gained a region. Resources re-themed 2026-10-04 (resource_retheme_190.py: 190 AD history, horses trimmed, silk only on the Silk Road).

Source: research/main190/db_out (the DB packed into !!190_expanded_region_test_main190.pack), map.hex for the region list. Generated by research/main190/new_regions_doc.py.
