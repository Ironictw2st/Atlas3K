# 190E x1.5: tile map / prop clearing proposal for the new regions

Status: **PROPOSAL ONLY.** Nothing in hex/, terrain/, ak/ or the kit was changed. The edit list (with unpadded and padded hex coordinates) is in `research/main190/proposal_x15/tilemap_proposal.json`, generated by `tilemap_proposal.py`. Previews: `previews/tilemap_proposal.png`, `previews/tilemap_proposal_south_zoom.png`.

## Where mountains come from

In game, a mountain near a town can come from three places, so each needs its own edit:
1. **Tile map area kind** (`caime_tilemap` output). Hexes painted with a mountain kind (`1820c1` cold, `b69237` temperate, `53b021` subtropical, `463a76` / `ffff7f` / `10ffe4`) get mountain tile prefabs from BOB. `96aa64` is generic land.
2. **AK layer props** (mountain / rock models in `ak/3k_dlc07_main_map/*.layer`).
3. **map.hex impassable flags** near the site.

### New land: Hexi corridor, Xiping, steppe (padded grid)

The tile map there is padding or old 190E frame, so it is replaced outright, not patched:
- playable corridor / valleys / steppe → generic `96aa64`: **53,952 hexes**;
- the Qilian wall and the steppe ranges band → cold mountain `1820c1` (190E's own north-west and north frame uses it): **17,592 hexes**;
- desert → generic: **59,714 hexes**; lakes (Qinghai, Dunhuang, Yuanquan, Juyan) → sea `3971b7`: **1,521 hexes**.
- **Old 190E mountain/rock props** whose new position lands on the new land: **86 on playable land and 36 on desert → remove**; 32 on the ranges → keep. The entities, with their layer file, id, model and position, are listed in the JSON under `new_land.props_remove`.

## Trees (rule 8)

Trees are handled by the existing `tree_clear.py` (TOWN_RING around new footprints, and along the new roads), run after the carve. Its counts depend on the carved footprints, so they are not in this list.

## How it slots into the build

1. **Tile map:** a new `tile_clear.py` step runs on the padded `caime_tilemap` output, before BOB Tilemap. It applies `tile_repaint` (and the tier-2 cells if approved) and the new-land plan, then re-runs `tile_repair`'s pattern fix so BOB doesn't hit unseen 7-hex patterns.
2. **Props:** `ak_main`'s `do_layer` drops the listed entities (match on layer + id, or on position + model, in both layer copies) before BOB Global Mesh and Terry file. BOB then rebuilds global_props.
3. **Impassable:** done in the region carve step on map.hex, together with the footprints. The user said regions come later, so this waits for the carve.
4. **Coordinates:** the JSON gives every hex in both the unpadded x1.5 grid and the padded grid (+140 cols; rows unchanged). The other session's build uses the padded one (1478x1133).

Note: the analysis used the 12:52 tile map and prop layers, before the pad. After the other session's terrain build, re-run `tilemap_proposal.py` against the new outputs to refresh the exact cells.
